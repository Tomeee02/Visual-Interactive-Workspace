# Project Summary
The Visual Workspace project is an innovative productivity tool designed to enhance note-taking and board organization through an interactive visual interface. It combines features from popular applications like Miro, Notion, and Trello, offering users a customizable canvas for effective information management. The project emphasizes user engagement through visually appealing elements, including emojis, and supports file uploads, allowing users to drag and drop files directly into their workspace.

# Project Module Description
The project consists of two main modules:
- **Frontend**: Developed with Vue 3, utilizing the Composition API, Vue Router, and Pinia for state management. The frontend is responsive and user-friendly, focusing on improved layout and aesthetics.
- **Backend**: Built using Python's Django framework, it provides a RESTful API for managing notes, boards, and files, ensuring data persistence through a SQLite database, with CORS support for seamless frontend-backend interaction.

# Usage
### Frontend Setup
1. Navigate to the frontend directory:
   ```bash
   cd /workspace/app/frontend
   ```
2. Install dependencies:
   ```bash
   pnpm install
   ```

### Backend Setup
1. Navigate to the backend directory:
   ```bash
   cd /workspace/app/backend
   ```
2. Create a virtual environment (optional):
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run migrations:
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```
5. (Optional) Create a superuser:
   ```bash
   python manage.py createsuperuser
   ```
6. Start the Django server:
   ```bash
   python manage.py runserver
   ```

### Automatic Startup
Run the startup script that handles both frontend and backend:
```bash
cd /workspace/app
./start.sh
```
